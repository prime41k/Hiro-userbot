Это документация к Hiro v9.0. Читай внимательно, чтобы не обосраться при настройке.

Установка
Создай config.json в папке со скриптом. Внутри пропиши api_id и api_hash. Если нет TTY, скрипт сдохнет с ошибкой. Создавай файл руками.

Ядро
База данных SQLite. Включен батчинг записи, чтобы не ебать диск тысячами мелких запросов. Хэши файлов считаются через быстрый CRC32. SHA256 вырезан, потому что он тормозит на частых операциях. Требуется скорость и стабильность.

Обработка ошибок ZSS
Встроен модуль ZSS. Если код падает, ты получаешь номер файла, строку и конкретный шаг для исправления. Читай логи, там все написано прямым текстом.

Команды модерации
mute, unmute, blacklist, unblacklist. Блокируй или разблокируй пользователей.
banhash. Банит хэш файла, чтобы он больше не пролезал.
purge, del. Чистит сообщения. Укажи количество или удали ответ.

Личные функции
ghost. Игнорирует всех, кроме добавленных в fav.
safe. Добавляет чат в исключения, чтобы бот там не триггерился.
afk, note, todo, remind, counter. Базовый органайзер. Ставишь задачу, бот выполняет.

Утилиты
echo, calc, passgen, encode, decode, hash, alias, filter. Генерация паролей, калькулятор, автоответы по триггерам. Ничего лишнего.

Функции для ЛС
read. Отмечает все сообщения в чате как прочитанные.
archive, unarchive. Прячет или возвращает чат в архив Telegram.
spamcheck. Анализирует последние 100 сообщений цели и выдает вердикт по активности.

Системные команды
eval. Выполняет произвольный Python-код. Если выполнишь там хуйню, вини только себя.
export, backup, vacuum. Выгрузка базы в JSON, сжатый бинарный бэкап и оптимизация места на диске.

Правила эксплуатации
Получаешь FloodWaitError — жди указанное время.
Получаешь MessageDeleteForbiddenError — у тебя нет прав на удаление.
Скрипт стабилен, если не лезть в код с кривыми руками.
